개인정보처리방침

시행일: 2026년 11월 11일 · 앱 사용 통계(아래 2·6·8번)는 2026년 11월 11일부터, 방문 통계 변경(아래 6번)은 2026년 11월 4일부터 적용돼요.

감자(GAMJA)는 이용자의 개인정보를 소중히 다뤄요. 이 방침은 홈페이지(webgamja.com)와 문의 메일에서 어떤 정보를 어떻게 쓰는지, 그리고 감자 앱이 개인정보를 어떻게 다루는지 설명해요.

1. 한눈에 보기

  • 감자 앱의 대화 내용과 만든 파일은 이용자의 폰에만 저장돼요. 감자 운영자는 이를 수집하거나 볼 수 없어요.
  • 홈페이지의 방문 통계는 구글 애널리틱스로 집계해요. 구글 차단 부가기능이나 쿠키 차단으로 집계를 막을 수 있어요(아래 6번).
  • 감자 콘솔(앱 화면)은 어떤 기능을 몇 번 썼는지 사용 횟수만 구글 애널리틱스로 집계해요. 대화 내용, 크루·방·파일 이름은 보내지 않아요.
  • 문의 메일을 보내시면 답변을 위해 보내신 주소와 내용을 받아요.

3. 이용 목적

  • 방문 통계: 어떤 내용이 도움이 되는지 파악하고 홈페이지를 개선해요.
  • 앱 사용 통계: 어떤 기능이 많이 쓰이는지 파악하고 감자를 개선해요.
  • 문의: 문의에 답하고 기록해요.
  • 접속 기록: 홈페이지를 안전하게 제공하고 오남용을 막아요(호스팅 업체가 처리).

4. 보관 기간과 파기

  • 방문 통계와 앱 사용 통계: 구글 애널리틱스의 데이터 보관 기간을 14개월로 설정해요. 그 뒤 자동으로 지워져요.
  • 문의 메일: 문의를 처리한 뒤 필요한 기간(길어도 1년)만 보관하고 지워요.
  • 접속 기록: 호스팅 업체의 정책을 따라요.

6. 쿠키와 통계 거부

  • 방문 통계와 앱 사용 통계를 위해 구글 애널리틱스가 이용자의 브라우저(앱 화면 포함)에 쿠키를 저장해요.
  • 앱 사용 통계 안내: 감자 콘솔에는 통계를 끄는 설정이 없어요. 앱 사용 통계를 원하지 않으시면 아래 방법으로 막아 주세요. 통계를 막아도 감자의 기능은 그대로 쓸 수 있어요.
  • 변경 안내: 서비스 초기에 최대한 모아서 개선하려고 2026년 11월 4일부터 브라우저의 "추적 안 함"이나 Global Privacy Control 신호와 관계없이 집계해요. 이전에는 이 신호를 켜 두면 집계하지 않았어요. 이번 변경은 서비스 초기라서 안내와 동시에 적용해요.
  • 끄는 방법: 구글의 Google Analytics 차단 부가기능을 설치하거나 브라우저에서 쿠키를 막거나 지우면 집계되지 않아요. 광고·추적 차단 앱을 써도 돼요. 폰을 비행기 모드나 와이파이 없는 상태로 쓰면 통계가 전송되지 않아요.

7. 이용자의 권리

이용자는 자신의 정보에 대해 열람, 정정, 삭제, 처리 정지를 요청할 수 있어요. help@webgamja.com으로 요청해 주세요. 본인 확인 뒤 지체 없이 처리해요.

8. 감자 앱과 개인정보

  • 저장 위치: 대화 기록, 만든 파일, 비밀번호 설정은 이용자의 폰 안에만 저장돼요. 감자 운영자의 서버로 보내지 않아요. (아래 앱 사용 통계의 사용 횟수는 예외예요.)
  • 앱 사용 통계: 감자 콘솔은 어떤 기능을 썼는지(앱 열기, 새 채팅 등)와 횟수를 구글 애널리틱스로 보내요. 대화 내용, 크루·방·파일 이름, 화면 주소는 보내지 않고, IP 주소 저장과 광고용 정보 사용은 꺼 둬요. 끄는 방법은 위 6번을 보세요.
  • Claude(Anthropic): 감자는 이용자 본인의 Claude 계정으로 Claude Code를 실행해요. 로그인은 Anthropic의 공식 화면에서 이뤄지고 감자는 로그인 정보를 보지 않아요. 이용자가 보낸 메시지는 Claude를 통해 Anthropic에 전달되고, 그 처리에는 Anthropic의 약관과 개인정보 방침이 적용돼요.
  • 업데이트 확인: 새 버전이 있는지 보려고 감자는 GitHub(공개 배포 저장소)에 접속해요. 이때 GitHub는 접속한 IP 주소 등을 알 수 있어요. 감자는 대화 내용이나 기기 식별 정보를 보내지 않아요.
  • GitHub 연결 기능(선택): 이용자가 직접 켜면 크루가 만든 파일이 이용자 본인의 비공개 GitHub 저장소에 기록돼요. 운영자에게는 전달되지 않아요.
  • 이용자가 "도구 상자"로 설치하는 프로그램이나 크루가 쓰는 외부 서비스는 각 제공자의 방침을 따라요.
