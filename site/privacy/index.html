개인정보처리방침

시행일: 2026년 11월 2일

감자(GAMJA)는 이용자의 개인정보를 소중히 다뤄요. 이 방침은 홈페이지(webgamja.com)와 문의 메일에서 어떤 정보를 어떻게 쓰는지, 그리고 감자 앱이 개인정보를 어떻게 다루는지 설명해요.

1. 한눈에 보기

  • 감자 앱의 대화 내용과 만든 파일은 이용자의 폰에만 저장돼요. 감자 운영자는 이를 수집하거나 볼 수 없어요.
  • 홈페이지의 방문 통계(구글 애널리틱스)는 동의한 분만 집계해요. 동의 전에는 아무것도 불러오지 않아요.
  • 문의 메일을 보내시면 답변을 위해 보내신 주소와 내용을 받아요.

2. 수집하는 정보와 방법

구분항목수집 방법
방문 통계 (동의한 경우만)쿠키로 만든 임의의 식별값, 본 페이지와 시각, 유입 경로, 브라우저·기기·화면 종류, 언어, 국가·도시 수준의 대략적인 위치구글 애널리틱스 4 (Google LLC)
문의이메일 주소, 문의 내용이용자가 help@webgamja.com으로 직접 보냄
접속 기록IP 주소, 접속 시각, 브라우저 정보 등홈페이지를 제공하는 호스팅 업체(GitHub, Inc.의 GitHub Pages)가 자동으로 기록

구글 애널리틱스는 IP 주소를 저장하지 않도록 설정하고, 광고 목적의 정보(광고 식별자, 구글 신호)는 쓰지 않도록 설정해요.

3. 이용 목적

  • 방문 통계: 어떤 내용이 도움이 되는지 파악하고 홈페이지를 개선해요.
  • 문의: 문의에 답하고 기록해요.
  • 접속 기록: 홈페이지를 안전하게 제공하고 오남용을 막아요(호스팅 업체가 처리).

4. 보관 기간과 파기

  • 방문 통계: 구글 애널리틱스의 데이터 보관 기간을 14개월로 설정해요. 그 뒤 자동으로 지워져요.
  • 문의 메일: 문의를 처리한 뒤 필요한 기간(길어도 1년)만 보관하고 지워요.
  • 접속 기록: 호스팅 업체의 정책을 따라요.

5. 제3자 제공과 국외 이전

운영자는 이용자의 정보를 판매하거나 다른 목적으로 넘기지 않아요. 다만 서비스 제공을 위해 아래 업체가 정보를 처리해요.

받는 곳목적항목이전 국가

이전 시점은 이용자가 홈페이지에 접속하거나 동의한 때이고, 보관은 위 4번의 기간을 따라요. 국외 이전을 원하지 않으시면 방문 통계에 동의하지 않으시면 돼요. (접속 기록은 홈페이지를 열 때 필요해요.)

6. 쿠키와 동의 철회

  • 방문 통계를 동의하면 구글 애널리틱스가 쿠키를 저장해요. 동의하지 않으면 저장하지 않아요.
  • 언제든 페이지 맨 아래의 "방문 통계 설정"에서 선택을 바꿀 수 있어요. 브라우저의 쿠키 삭제 기능으로 이미 저장된 쿠키를 지울 수도 있어요.
  • 화면 밝기(밝게/어둡게) 선택은 이용자의 브라우저에만 저장되고 서버로 보내지 않아요.

7. 이용자의 권리

이용자는 자신의 정보에 대해 열람, 정정, 삭제, 처리 정지를 요청할 수 있어요. help@webgamja.com으로 요청해 주세요. 본인 확인 뒤 지체 없이 처리해요.

8. 감자 앱과 개인정보

  • 저장 위치: 대화 기록, 만든 파일, 비밀번호 설정은 이용자의 폰 안에만 저장돼요. 감자 운영자의 서버로 보내지 않아요.
  • Claude(Anthropic): 감자는 이용자 본인의 Claude 계정으로 Claude Code를 실행해요. 로그인은 Anthropic의 공식 화면에서 이뤄지고 감자는 로그인 정보를 보지 않아요. 이용자가 보낸 메시지는 Claude를 통해 Anthropic에 전달되고, 그 처리에는 Anthropic의 약관과 개인정보 방침이 적용돼요.
  • 업데이트 확인: 새 버전이 있는지 보려고 감자는 GitHub(공개 배포 저장소)에 접속해요. 이때 GitHub는 접속한 IP 주소 등을 알 수 있어요. 감자는 대화 내용이나 기기 식별 정보를 보내지 않아요.
  • GitHub 연결 기능(선택): 이용자가 직접 켜면 크루가 만든 파일이 이용자 본인의 비공개 GitHub 저장소에 기록돼요. 운영자에게는 전달되지 않아요.
  • 이용자가 "도구 상자"로 설치하는 프로그램이나 크루가 쓰는 외부 서비스는 각 제공자의 방침을 따라요.

9. 아동의 개인정보

감자와 홈페이지는 만 14세 미만 아동을 대상으로 하지 않아요. 만 14세 미만 아동의 정보를 알면서 수집하지 않으며, 알게 되면 지체 없이 지워요.

10. 안전성 확보 조치

운영자는 이용자 정보에 접근할 수 있는 사람을 최소로 하고, 접속 구간은 HTTPS로 보호해요. 감자 앱은 비밀번호 시도 횟수를 제한하고 대화와 파일을 이용자의 폰 안에서만 처리하도록 만들었어요. 코드는 공개돼 있어서 누구나 확인할 수 있어요.
